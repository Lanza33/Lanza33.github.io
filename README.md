# Aqua Rescue Systems — Webseite

Professionelle italienischsprachige Marketing-Website für ARS (Aqua Rescue Systems) — spezialisiert auf autonome Wasserrettungsroboter.

## 🎯 Features

- **Responsive Design** — Optimiert für Desktop, Tablet und Mobile
- **Hero Video Banner** — Mit Overlay-Grafiken und professioneller Typografie
- **Produktpräsentation** — Detaillierte Showcase mit Spezifikationen
- **Modals für rechtliche Inhalte:**
  - Note Legali (Impressum)
  - Privacy Policy (GDPR-konform)
  - Cookie Policy
  - Kontaktformular

## 🛠 Technologie

- **HTML5** — Semantisches Markup
- **CSS3** — Mit Tailwind CSS Integration
- **JavaScript** — Für Scroll-Animationen & Modals
- **SVG Graphics** — Professionelle Logos

## 📱 Responsive Breakpoints

- Desktop: 1200px+
- Tablet: 900px
- Mobile: 600px

## 🚀 Deployment

Die Webseite kann auf verschiedene Weisen deployed werden:

### GitHub Pages (kostenlos)
1. Repository Settings → Pages
2. Source: main branch
3. Live unter: `https://username.github.io/repository-name`

### Alternativen
- Netlify (mit automatischem Deploy bei Push)
- Vercel
- Eigener Server
